# 黑秤記・今夜體驗

本庫是《黑秤記》今夜體驗的美術素材庫，只收下面 13 個 PNG。圖檔依原檔放入，沒有改內容、也沒有再壓縮。

## 背景

`assets/backgrounds/`，尺寸皆為 **1920×1080**。

- `bg_shop_gate.png`
- `bg_shop_interior.png`
- `bg_hill_mudpit.png`
- `bg_finance_flat.png`
- `bg_blackmarket_room.png`

## 葉衡立繪

`assets/sprites/yeheng/`。去背全身立繪，同一角色的表情差分（透明背景 PNG）。

- `yeheng_normal.png` 平常
- `yeheng_smile.png` 微笑
- `yeheng_laugh.png` 大笑
- `yeheng_angry.png` 生氣
- `yeheng_sad.png` 難過
- `yeheng_surprised.png` 驚訝
- `yeheng_shy.png` 害羞
- `yeheng_special.png` 特殊

## 檔名規約

- 全小寫，單字以底線 `_` 分隔，副檔名 `.png`。
- 背景：`bg_<場景>.png`，放在 `assets/backgrounds/`。
- 葉衡：`yeheng_<表情>.png`，放在 `assets/sprites/yeheng/`。
- 不收 `yeheng_special_v2`、`yeheng_special_v3`，也不收半身舊檔。
